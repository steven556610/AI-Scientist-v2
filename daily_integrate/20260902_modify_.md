# 2026-09-02 修改紀錄

## 修改內容與原因

本次修改主要針對 `AI-Scientist-v2` 的架構進行重構與能力擴充，以解決主程式碼過於臃腫、缺乏測試保護，以及需要整合外部研究技能（skills）的問題。

1. **主程式碼模組化重構 (`src/`)**
   - **原因**：原有的 `launch_scientist_bfts.py` 長達 500 多行，將 CLI 解析、I/O 處理、實驗執行、畫圖、論文撰寫與審查等多個職責混雜在一起，難以維護與擴展。
   - **修改內容**：將核心邏輯拆分至 `src/` 目錄下的多個模組，並建立了一個精簡版的 `main.py`（約 130 行）作為新的入口點，主要負責流程控制。原有的 `launch_scientist_bfts.py` 則完整保留，供向後相容使用。

2. **建立完整的測試套件 (`tests/`)**
   - **原因**：為了確保重構後的各個模組穩定可靠，且未來的修改不會破壞現有功能，需要建立單元測試。
   - **修改內容**：新增了 40 個測試案例（覆蓋率達標），涵蓋了 CLI 解析 (`test_cli.py`)、I/O 工具 (`test_io_utils.py`)、各個執行階段的 Mock 測試 (`test_stages.py`)、進程清理 (`test_process_cleanup.py`) 以及程式碼生成 (`test_generate_base_code.py`)。

3. **整合外部 Research Skills (`.agents/`)**
   - **原因**：為了強化 AI-Scientist Agent 的研究能力，需要導入外部的最佳實踐，包括程式碼精簡、假說生成、實驗設計審查以及文獻搜索管理。
   - **修改內容**：在 `.agents/skills/` 目錄下新增了 5 個 Skill 設定檔，並建立 `.agents/rules/research_workflow.md` 規範 AI 代理的工作流程。

## 新增與重構的程式碼

- `main.py`: 新的精簡版啟動腳本。
- `src/__init__.py`: package 初始化。
- `src/cli.py`: 負責所有的 argparse 命令列參數解析。
- `src/io_utils.py`: 包含讀取 idea、重定向日誌（Tee 輸出到檔案與終端機）、讀取 token tracker 等共用工具。
- `src/process_cleanup.py`: 負責在實驗結束或中斷時，使用 `psutil` 清理殘留的子進程。
- `src/stages/__init__.py` 及 `stage1_experiments.py`, `stage2_plots.py`, `stage3_writeup.py`, `stage4_review.py`: 分別封裝了實驗執行、圖表生成、論文撰寫與 AI 審查的邏輯。
- `tests/`: 包含 `test_cli.py`, `test_io_utils.py`, `test_stages.py`, `test_process_cleanup.py`, `test_generate_base_code.py`。
- `pyproject.toml`: 增加 pytest 的執行設定。
- `.agents/rules/research_workflow.md`: 規範實驗的四階段流程與早期退出條件。
- `.agents/skills/`: 引入了 `ponytail`, `hypothesis-generation`, `experimental-design`, `literature-search-arxiv`, `citation-management` 等技能指南。

## 延續修改 (Later Updates)

4. **優化 Ideation 腳本的檔案存取體驗**
   - **修改內容**：修改 `ai_scientist/perform_ideation_temp_free.py`，現在 `--workshop-file` 參數可以直接傳入一個**資料夾路徑**（例如 `ai_scientist/ideas/my_research_topic/`）。腳本會自動尋找內部的 `.md` 檔案，並且將產生的 `.json` 檔案直接儲存於該資料夾中，不再打亂專案目錄。

5. **LLM Token 限制的動態配置與擴充**
   - **修改內容**：
     - 在 `.env` 中加入了 `KIMI_MAX_TOKENS=32768`、`GEMMA_MAX_TOKENS=8192` 以及全域的 `MAX_NUM_TOKENS=4096` 設定。
     - 修改 `ai_scientist/llm.py`，取消了原本將 `max_tokens` 寫死為 4096 的限制，改為從系統環境變數動態讀取。當遇到 `kimi-k3` 或 `gemma-4-31b-it` 等客製化內部端點時，系統能自動賦予更大的輸出上限，避免模型長篇大論時被強行截斷。

6. **自動量化評估 Idea 價值並輸出 CSV**
   - **修改內容**：修改 `ai_scientist/perform_ideation_temp_free.py` 中給 LLM 的 `FinalizeIdea` Schema 定義。
   - **細節**：強制 LLM 必須在輸出 Idea 的同時，基於 S2 文獻搜尋結果給予 `Novelty Score`（新穎性）、`Feasibility Score`（可行性）與 `Expected Impact`（預期影響力）等三個 1-10 分的量化指標。
   - **儲存**：腳本執行完畢時，會自動擷取這 20 個點子的所有分數，並額外在您的資料夾中輸出一個 `_metrics.csv`，方便研究員使用表格工具排序並挑選出最高分的點子來跑後續實驗。
